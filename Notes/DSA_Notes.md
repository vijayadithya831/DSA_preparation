#### Tree Data Structure (Non Linear)

* Tree is a data structure which stores data in an hierarchical manner. Meaning, the data are related to each other based on levels. (higher level, lower level)
* Tree is used to represent data items which have hierarchical relationship among them. Real life example includes a college staff and student collection, where the principal will be the highest level node, then the head of the departments, below them comes the staff and below them comes the students. So, we can clearly see there are levels (designation) in this collection of people (data items). So, to maintain this hierarchy while storing, we can use tree data structure.
